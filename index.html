Datalake-MCP

Un server MCP che espone un Azure Data Lake Storage Gen2 a Claude: naviga file e cartelle ed estrae dati da CSV, Parquet, XML, testo e markdown, con letture in streaming e paginazione pensate per la scala.

Leggi il README Esplora il codice

Cosa fa

Il server si autentica su un account Azure Data Lake Gen2 (accountName/accountKey) ed espone via protocollo MCP un set di tool che permettono a Claude di navigare la struttura del datalake e leggere il contenuto dei file, applicando filtri, proiezioni e paginazione senza mai caricare un intero file in memoria.

Navigazione

Elenca filesystem, cartelle e file, con metadati (dimensione, ultima modifica).

Lettura multi-formato

CSV, Parquet, XML tabellare, testo (.txt) e markdown (.md), ciascuno con il proprio reader.

Streaming efficiente

Lettura in streaming e a row-group/elemento, con caricamento differito dei byte dal datalake.

Paginazione

Ogni lettura si ferma a un limite di righe/linee e restituisce un nextOffset per proseguire.

Architettura

Il server è un host .NET Generic Host su trasporto stdio, con un servizio di reader dedicato per ogni formato.

Claude → MCP (stdio) → Tools/DataLakeTools.cs → Reader Services → Azure Data Lake Gen2
FileResponsabilità
Configuration/DataLakeOptions.csOpzioni di connessione (AccountName / AccountKey / DefaultFileSystem)

Tool MCP esposti

Ogni tool è pensato per essere composto: prima si esplora, poi si legge lo schema, infine si estraggono i dati a pagine.

ToolDescrizione
list_filesystemsElenca i filesystem (container) dell'account
list_directoryElenca file e directory in un percorso (opzionalmente ricorsivo)
get_file_infoMetadati di un file (dimensione, data ultima modifica)
read_csvLegge un CSV, con maxRows, delimitatore configurabile e offset
get_parquet_schemaSchema (colonne/tipi) di un Parquet senza leggerne i dati
read_parquetLegge un Parquet, con maxRows, proiezione colonne e offset
read_textLegge un file di testo (.txt), con maxLines e offset
read_markdownLegge un file markdown (.md), con maxLines e offset
get_xml_schemaSchema (attributi/elementi) dell'elemento record di un XML tabellare
read_xmlLegge un XML tabellare, con elemento record e colonne opzionali, e offset

Paginazione

Le risposte dei tool di lettura sono soggette al limite di dimensione dei tool call (circa 1 MB). Quando un file eccede maxRows/maxLines, il risultato riporta truncated: true e un nextOffset.

  1. Chiama il tool con offset: 0.
  2. Se truncated è true, richiama lo stesso tool con offset = nextOffset.
  3. Ripeti finché truncated non è false (nextOffset sarà null).

Configurazione ed esecuzione

Le credenziali dell'account non vanno mai committate: usa i .NET user-secrets in sviluppo.

dotnet user-secrets init
dotnet user-secrets set "DataLake:AccountName" "<nome-account>"
dotnet user-secrets set "DataLake:AccountKey" "<chiave-account>"
dotnet user-secrets set "DataLake:DefaultFileSystem" "<container-predefinito>"

dotnet build
dotnet test
dotnet run --project src/Datalake.Mcp.Server

Il server comunica via stdio secondo il protocollo MCP: va registrato come server MCP nel client (es. Claude Desktop / Claude Code). Un esempio di configurazione è disponibile in claude_desktop_config.example.json.
